# Selected Works · 影像与产品

静态作品展示页：首片《观看的重量》完整直接播放、创作起点与原始修订记录，配音短剧、交互作品及产品原型的真实状态。

## GitHub Pages

从 `main` 分支根目录发布，无构建步骤、无后端、无运行时模型调用。所有本地资源使用相对路径，兼容仓库子路径。`.nojekyll` 已提供。

## 本地预览

在此目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000`。

## 范围

详见 [公开内容清单](PUBLICATION-MANIFEST.md)。只收录已选定的001成片；002未通过样片不包含在本包。公开源码不改变已链接产品的登录、授权或后端访问。

没有密钥、私人对话、账号配置、生成语音账户数据、后端代码或缓存。公开展示不等于对整个项目授予统一的开源许可；馆藏素材条件与署名见页面底部和 `assets/artwork-sources.json`。
